# SearXNG: find and check an original source

The working demonstration is **search → result URL → original page → supported answer**. German: [DE/START.md](DE/START.md). English: [EN/START.md](EN/START.md).

On 8 October 2026 the existing assistant MCP connection really found the official SearXNG Search API documentation and then opened that returned URL. [Evidence and remaining engine warnings](TESTS/STATUS.md). The earlier failed test is preserved; it is not the conclusion of this working demonstration.

Use your existing local SearXNG endpoint and installed adapter. The kit includes a read-only search test, preparation helper, MCP template and blank source-check sheet. It does not install or start services or models. Queries still reach external search services.

Downloads: [German](downloads/SEARX-LERNPAKET-DE.zip), [English](downloads/SEARX-LERNPAKET-EN.zip). The fresh search record is an author's example, not a pre-filled result from your machine. Existing files and historical evidence are preserved under ARCHIV and TESTS.
