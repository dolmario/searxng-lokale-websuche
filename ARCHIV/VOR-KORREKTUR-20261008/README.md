# Local AI web search — beginner practice

German: [DE/START.md](DE/START.md). English: [EN/START.md](EN/START.md).

Prepare a public query, test an existing loopback SearXNG JSON endpoint manually, then connect a separately installed MCP adapter and check original sources. This repository does not include SearXNG, Node, models, an AI assistant, private configs or a tested universal installer. Existing service and model processes stay under your control. The preparation helper has been tested offline; its generated HTTP request was not executed during that test.

A later [actual connector check](TESTS/STATUS.md) returned three irrelevant results and engine warnings. The tool call completed; the source-finding goal failed. This is evidence for checking sources, not a successful installation or search-quality promise.

Downloads: [German](downloads/SEARX-LERNPAKET-DE.zip), [English](downloads/SEARX-LERNPAKET-EN.zip). Each includes the helper, templates, blank evaluation and primary-source links. No search result or model answer is pre-filled.
